# Data Structures Repository

Welcome to my official Data Structures repository! As an Information Systems (IS) student, this space is dedicated to documenting my academic progress, practical lab assignments, and programming exercises developed during my study of core computer science concepts.

## Repository Contents
This collection includes detailed implementations and hands-on solutions for various fundamental data structures using the Java programming language:
- **Single Linked Lists:** Practical implementations demonstrating node creation, pointer manipulation, and fundamental list traversal operations.
- **Double Linked Lists:** Advanced list structures featuring bi-directional navigation with both forward and backward pointers.
- **Circular Linked Lists:** Exercises focusing on continuous loop structures where the tail node points back to the head.
- **Binary Search Tree (BST):** Comprehensive tree-based algorithms and structural operations designed to maintain sorted hierarchical data.

## Purpose
The primary goal of this repository is to serve as a structured personal reference, a coding portfolio, and a practical application of data structures algorithms within my IS studies. Feel free to explore the source code and implementation files within each respective folder.
